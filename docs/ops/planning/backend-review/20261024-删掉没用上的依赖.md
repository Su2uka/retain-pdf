# 删掉没用上的依赖

服务端工程审查 L2 的一部分（见[服务端工程审查](./20261024-服务端工程审查.md)）。

## 删了什么

拆包以后留在清单里、代码里一处都没用到的依赖（`git grep -w <crate>` 在包的 `src/`、`tests/`、`build.rs` 里都是 0；
删掉以后 `cargo build --workspace --all-targets` 没有错误和警告）：

| 包 | 删掉的依赖 |
|---|---|
| `backend/api`（rust_api） | `thiserror`、`once_cell`、`mime_guess`、`walkdir`、`hmac`、`getrandom`、`argon2`、`serde_urlencoded`（审查列的 8 个） |
| `backend/cli` | `serde` |
| `backend/jobs`（retain-jobsd） | `serde` |
| `retainpdf-runner` | `libc` |

这些库别的包还在用的照旧在 `Cargo.lock` 里（如 `argon2` 在账号包、`mime_guess` 在文件包），`Cargo.lock` 只少了这几个包的依赖边。

## 没做的（L2 其余）

- `tower-http` 0.5 和 0.6 两份、`tokio-tungstenite` 0.21 和 0.24 两份：升 `tower-http` 要改 CORS、`TraceLayer` 的用法，
  终端代理换 `tungstenite` 要改帧转换，属于 AI 那一块（助手终端，先不管）。
- `[workspace.dependencies]` 统一版本、`tokio` 去掉 `full`：动所有包的清单，收益是整洁，另说。
- `[profile.release]`（LTO、`codegen-units`、`strip`）：会让发布构建更慢，Docker arm64 在 QEMU 下已经要近一小时，
  要先量体积和构建时间再定。
