## 做了什么

**新包 `retain-pdf-glossaries`**，放在 `backend/packages/retain-pdf-glossaries`：
- **代码**：`services/glossaries/` 整个目录挪过去。
  - `mod.rs` 改名 `lib.rs`，就是这个包的门面；
  - 子模块 `api`、`csv`、`entries`、`records` 照旧私有；
  - 门面导出的东西从 `pub(crate)` 改成 `pub`。
- **依赖**：只有底座包 `retain-pdf-api-base`、`retain-pdf-core`、`retain-pdf-data`，再加 `csv`。
  它用不了 rust_api 的任何东西（`AppState`、`services`、`routes`），这一点编译器就能保证。
- **路径**：`crate::error`、`crate::db`、`crate::models` 改成直接写对应的包名。

**测试跟着挪进包里**：
- 11 个测试原来通过 rust_api 的测试工具搭一个完整的 `AppState`，其实只用到了里面的数据库。
- 现在在临时目录里直接建一个 `Db`。测试内容一行没改。

**rust_api 接上它**：
- `services/mod.rs` 里写 `pub(crate) use retain_pdf_glossaries as glossaries;`。
- 路由、建任务、`api_tests` 里写的 `crate::services::glossaries::…` 一行都不用改。
- 路由导入白名单也照旧。

**架构检查**：
- 新加"已经拆成独立包的领域"名单 `EXTRACTED_DOMAINS`。对名单里的领域，`check_domain_facades` 检查三件事：
  1. `services/` 下不许再有它的目录，免得拆了一半，又有人把代码写回去；
  2. `services/mod.rs` 里必须有接上它的那一行；
  3. 包的 `lib.rs` 不许 `pub mod`。
- 配了 2 个单测；往真实代码里故意写了 `pub mod api;`，会报。单测一共 62 个。
- 两条原来管术语表内部的规则删掉了，现在由编译器保证：
  - "外面不许点进 `glossaries::csv`、`entries`、`records`"：这些子模块在别的包里，本来就是私有的；
  - "模型要从 `models::api` 等门面导入"：拆出去的包直接依赖 `retain-pdf-core`。
- 领域依赖方向照旧按 `services::glossaries` 算，`jobs → glossaries` 这一条还在登记表里。

**交付**：
- 加进工作区成员；
- `Dockerfile.app` 的两个阶段都 `COPY` 新包；
- 合并前的 `cargo test`（CLAUDE.md）加上 `-p retain-pdf-glossaries`。

## 拆一个领域包的样板

后面的领域照着做：

1. **确认依赖**：领域里除了测试，只用到底座包、`retain-pdf-core`、`retain-pdf-data`（和已经拆出去的包）。
   用到别的东西，先把那样东西往下放。
2. **挪代码**：`git mv backend/api/src/services/<领域> backend/packages/retain-pdf-<领域>/src`，
   `mod.rs` 改名 `lib.rs`。
3. **改路径和可见范围**：
   - `crate::error` → `retain_pdf_api_base::error`；
   - `crate::job_loading` → `retain_pdf_api_base::job_loading`；
   - `crate::db` → `retain_pdf_data::db`；
   - `crate::models` / `config` / `storage_paths` → `retain_pdf_core::…`；
   - 门面导出的东西改成 `pub`。
4. **改测试**：只用数据库的，直接建 `Db`；真要整个 `AppState` 的，留在 rust_api 的 `api_tests` 里。
5. **接上**：在 rust_api 里加依赖，`services/mod.rs` 里写 `pub(crate) use retain_pdf_<领域> as <领域>;`。
6. **登记**：
   - 加进 `EXTRACTED_DOMAINS`；
   - 删掉那些现在由编译器保证的、按这个领域内部路径写的检查规则；
   - 加进工作区成员、`Dockerfile.app` 的两个阶段、CLAUDE.md 的 `cargo test` 列表。
7. **跑全部检查**：三份快照都不该变。
