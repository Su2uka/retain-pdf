## 做了什么

现有的 9 个 Rust 包按规划统一改成 `retain-pdf-*`。这次只改包名，目录名和可执行文件名都不变：

| 目录 | 原包名 | 新包名 | 新 crate 名 | 可执行文件（不变） |
|---|---|---|---|---|
| `backend/api` | `rust_api` | `retain-pdf-api` | `retain_pdf_api` | `rust_api`、`retainpdf-agent` |
| `backend/packages/retain-core` | `retain-core` | `retain-pdf-core` | `retain_pdf_core` | |
| `backend/packages/retain-data` | `retain-data` | `retain-pdf-data` | `retain_pdf_data` | |
| `database/retain-db` | `retain-db` | `retain-pdf-db` | `retain_pdf_db` | |
| `backend/packages/retain-config` | `retain-config` | `retain-pdf-config` | `retain_pdf_config` | |
| `backend/packages/retain-proc` | `retain-proc` | `retain-pdf-proc` | `retain_pdf_proc` | |
| `backend/packages/retain-jobs` | `retain-jobs` | `retain-pdf-runner` | `retain_pdf_runner` | |
| `backend/jobs` | `retain-jobsd` | `retain-pdf-runnerd` | | `retain-jobsd` |
| `backend/cli` | `retainpdf-cli` | `retain-pdf-cli` | | `retainpdf` |

具体改动：
- **`Cargo.toml`**：包名和依赖都换成新名字。
- **Rust 代码**：约 80 个文件的 `use retain_core::…`、`rust_api::…` 这类路径，跟着换成新的 crate 名。
- **`backend/api` 的可执行文件**：加了 `[[bin]] name = "rust_api"`，可执行文件名保持原样。下面这些都按这个名字找它：
  - Docker 的 `entrypoint-app.sh`；
  - 桌面版的打包脚本；
  - `ops/development/dev_stack.py`；
  - CI 的桌面版打包。
- **其余两个可执行文件**：`retain-jobsd`、`retainpdf` 本来就单独写了 `[[bin]]`，不用改。
- **命令里的 `cargo -p`**，换成新包名：
  - `CLAUDE.md` 的合并前检查；
  - 三份快照文件开头写的重新生成命令，以及生成它们的测试代码；
  - `backend/api/scripts/check_test_filters.py`（CI 的 Rust API Architecture 会跑它）；
  - README 和文档里的命令。
- **新旧包名对照表**：写在 `docs/core/contributing/backend.md`。

## 要注意的一处：日志过滤

`rust_api` 默认的日志过滤原来是 `rust_api=info,tower_http=info`。

库的 crate 名改成 `retain_pdf_api` 以后，库里打的日志，目标名就变成了 `retain_pdf_api::…`。
如果过滤规则不跟着改，这些日志会被悄悄过滤掉。现在的默认值是
`retain_pdf_api=info,rust_api=info,tower_http=info`：
- `rust_api` 是可执行文件自己（`main.rs`）的目标名；
- 设了 `RUST_LOG` 环境变量时，照旧以它为准。

**如果哪里手写了 `RUST_LOG=rust_api=debug`，要改成 `RUST_LOG=retain_pdf_api=debug`。**
仓库里查过，没有地方这样写。

## 没改的

- **目录名**：没改。Dockerfile 的 `COPY`、文档链接、测试里的路径都按目录名写，改了牵动太大，也没有好处。
  文档里写的 `retain-core`、`retain-jobs` 指的是目录。
- **数据目录**：数据目录里的 `rust_api/` 子目录（`data_root.join("rust_api")`）是数据布局，不是包名，没动。
- **CI**：CI 的 `cargo test --workspace`、`cargo build --workspace --bins` 不按包名指定，不受影响。
- **前端**：前端有一处注释写着 `cargo test -p retain-core`
  （`frontend/web/tests/platform/mock-job-payload-contract.test.mjs` 第 17 行），
  现在应写 `cargo test -p retain-pdf-core`，只是注释，不影响运行。
