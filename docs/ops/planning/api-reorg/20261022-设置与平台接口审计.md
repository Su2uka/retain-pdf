## 二、按已定的规矩改（对前端只增不改）

- **409 带 `reason`**：凭据、备份、同步的 409 都没有。坏备份、来自新版本的备份现在是 400，按 400/409 的分工应是 409（A7、C7）。
- **不认识的字段 400**：校验接口、凭据列表、术语表列表的查询、`PUT /sync` 的请求体（A8、B9、C9）。
- **不分页的列表写进约定**：`/glossaries`、`/credentials`、`/providers/ocr`、`/backups` 都是小列表，在 `03-分页.md` 写明"不分页"；术语表 `?q=` 空串现在返回空表，改成不过滤（B9、A12、C13）。
- **统一的报错信封**：模型执行器内部接口用 axum 原生 `Json`/`Path`，报错不走统一信封，还在鉴权前先解析请求体；`/ready` 503 时信封里 `code` 仍是 0（C11、C12）。
- **术语表 PUT 加可选版本号**：请求体加 `expected_updated_at`，给了就比，不等 409 `glossary_changed`；不给照旧。界面和 AI `term-set` 都是"读整张、改、写整张"，两边同时改后写的会盖掉先写的（B6）。
