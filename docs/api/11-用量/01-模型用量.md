# 模型用量

模型 token 用量的汇总，三个接口返回同一个结构，契约是
[`token-usage.v1`](../../../contracts/token-usage.v1.schema.json)（前端类型从 `@retainpdf/contracts/token-usage` 导入）。

| 接口 | 谁能用 | 范围 |
|---|---|---|
| `GET /api/v1/jobs/{job_id}/reports/usage` | signed | 一个任务（含它的原地精修、重渲染） |
| `GET /api/v1/documents/{document_id}/usage` | signed | 一本书的全部任务，加上问这本书时 AI 助手花的 |
| `GET /api/v1/usage` | signed | 现存的全部任务，加上 AI 助手；删掉的书不再计入 |

都不分页，没有查询参数。

## 返回

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "scope": "all",
    "totals": {
      "requests": 120, "requests_without_usage": 2,
      "input_tokens": 830000, "output_tokens": 210000, "total_tokens": 1040000,
      "cache_hit_tokens": 400000, "cache_reported_input_tokens": 790000,
      "cache_write_tokens": 0, "reasoning_tokens": 12000
    },
    "by_stage": [{ "stage": "translation", "label": "翻译", "group": "translation", "requests": 100, "...": "同 totals" }],
    "by_model": [{ "model": "deepseek-chat", "host": "api.deepseek.com", "requests": 100, "...": "同 totals" }],
    "by_month": [{ "month": "2026-10", "requests": 120, "...": "同 totals" }],
    "jobs_counted": 8,
    "jobs_estimated_from_reports": 1,
    "first_at": "2026-09-30T23:59:00Z",
    "last_at": "2026-10-22T08:00:00Z"
  }
}
```

- `scope`：`job` / `document` / `all`。
- 每一组（`totals`、`by_stage`、`by_model`、`by_month` 的每一项）都是同一套计数：
  - `requests_without_usage`：服务商没报用量的请求数，这些请求的 token 没算进来；
  - `cache_hit_tokens`、`cache_write_tokens` 包含在 `input_tokens` 里，`reasoning_tokens` 包含在 `output_tokens` 里；
  - 缓存命中率 = `cache_hit_tokens / cache_reported_input_tokens`，分母为 0 表示不知道（服务商没报缓存）。
- `by_stage` 按 `total_tokens` 从大到小；`group` 是 `translation` / `preparation` / `refine` / `assistant` / `other`，界面按它分组，`label` 是中文名。
- `by_month` 按月份从早到晚，`month` 是 `YYYY-MM`（UTC）。
- `jobs_estimated_from_reports`：有台账之前的旧任务，从翻译诊断和精修报告折算，只算得出输入输出（没有缓存、思考明细），
  界面可以注明"早期任务按报告估算"。
- `first_at`、`last_at`：最早、最近一条用量的时间，没有用量时为 `null`。

## 数据从哪来

- 每个任务的台账 `artifacts/token-usage.v1.jsonl`：流水线每次模型返回追加一行；
- AI 助手的台账 `<data_root>/usage/assistant.v1.jsonl`；
- 有台账之前的旧任务：`translation_diagnostics.json` 和精修报告里的 `token_usage`。

台账是追加写的文本，坏行（写到一半断电之类）跳过，不让整份汇总失败。
时间戳取不出 `YYYY-MM`（被手改过、别的工具写的）的那一行照样计入总数和按阶段、按模型，只是不进 `by_month`，
也不当 `first_at` / `last_at`（2026-10-22 起；以前一行怪时间戳会让整个接口 500）。

## 报错

- `GET /jobs/{job_id}/reports/usage`：库里没有这个任务、任务目录也没有时 404；库里删了记录但目录还在，照样 200。
- `GET /documents/{document_id}/usage`：书不存在 404；有书没任务 200、全零。
- `GET /usage`：多用户模式下只算当前账号的任务（不含助手）。

每次请求都把涉及的任务目录读一遍，没有缓存；任务多了以后再加（见
[服务商探测与用量](../../ops/planning/api-reorg/20261022-服务商探测与用量.md)）。
