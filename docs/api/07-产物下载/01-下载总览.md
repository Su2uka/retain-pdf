# 下载总览

所有文件只有两种地址：**任务的文件** `/jobs/{job_id}/files/…` 和**书的文件**
`/documents/{document_id}/files/…`。文件名一律是"内容.格式"，看名字就知道是什么、什么格式。
旧的文件地址已于 2026-10-18 全部删除（返回 `404`），本页末尾留着新旧对照，方便改老代码。

整理的来由和完整的新旧对照见
[任务与文件接口整理](../../ops/planning/api-reorg/20261015-任务与文件接口整理.md)。
返回的状态码、类型、下载文件名、缓存头钉在 `backend/api/docs/file-responses.txt`。

任务详情、书籍详情、文档列表、Markdown 视图里返回的文件链接（`pdf_url`、`markdown.raw_url`、`bundle_url`、
`cover_url`、`source_pdf_url`、产物清单的 `resource_url`……）2026-10-17 起都是这两种新地址；
原来默认下载的（全部打包、原文 PDF、中间产物）带 `?download=1`。
产物列表、产物清单的链接（`manifest_path`/`manifest_url`、`links.artifacts_*`、`links.artifacts_manifest_*`、`actions.open_artifacts`）
也已换成 `/jobs/{id}/files`（见[产物清单链接换成文件清单](../../ops/planning/api-reorg/20261017-产物清单链接换成文件清单.md)）；
产物清单里 `source_pdf` 一项知道书编号时是 `/documents/{doc}/files/source.pdf?download=1`。
查不到书编号时不再退回旧地址：`cover_url`、`thumbnail_url` 给 `null`，`/files` 的 `source.url` 是空串、`ready` 是 `false`
（2026-10-18；有原文的任务都会登记成书，实际只有原文文件不在的任务会这样）。
这些字段名没动，只是值变了；`/files` 返回的结构和已删除的 `/artifacts`、`/artifacts-manifest` 不一样，读这些链接的代码要按 `/files` 的结构解析。
逐个字段的对照见[返回链接换新地址清单](../../ops/planning/api-reorg/20261017-返回链接换新地址清单.md)。

## 通用约定

- 默认在浏览器里打开（`Content-Disposition: inline`，带好文件名，另存为时名字是对的）；
  加 `?download=1` 直接下载（`attachment`）。
- 标着"按需生成"的文件第一次请求时才生成，会慢一些；同一份同时被请求只生成一次，之后走缓存。
- 文件名写错、或者这一组没有这个文件：`404`。文件还没产出（任务没跑完）：`404`，提示 `… not ready`。
  全部打包要求任务已成功，否则 `409`。

## 任务的文件

```http
GET /api/v1/jobs/{job_id}/files
GET /api/v1/jobs/{job_id}/files/output/{name}
GET /api/v1/jobs/{job_id}/files/pages/{page}.jpg
GET /api/v1/jobs/{job_id}/files/internal/{name}
```

按"给谁用"分三组：

| 组 | 给谁用 | 多用户模式 |
|---|---|---|
| `output/` | 用户：下载、在浏览器里看 | 网站账号可用（自己的任务） |
| `pages/` | 界面：译文单页预览图 | 网站账号可用（自己的任务） |
| `internal/` | 排查问题 | **只给管理员**；网站账号请求返回 `403`，清单里也没有这一组 |

### `output/`：成品

| 文件名 | 内容 | 按需生成 |
|---|---|---|
| `translated.pdf` | 译文 PDF | |
| `side-by-side.pdf` | 中英对照 PDF | 是 |
| `translated.docx` | 译文 Word；`?dpi=` 选背景清晰度（72～300） | 是 |
| `ocr.md` | 原文 Markdown（OCR 识别结果，**不是译文**） | |
| `ocr.zip` | 原文 Markdown + 图片 | 是 |
| `ocr/images/{path}` | Markdown 里引用的图片 | |
| `all.zip` | 全部成品打包（只给成功的任务） | 是 |

### `pages/`：预览图

`pages/3.jpg` 是译文第 3 页（页码从 1 开始）。`?width=`（240～2400，默认 1200）、`?dpi=`（≤300）。
同一个地址内容不变，响应带 `Cache-Control: public, max-age=31536000, immutable`。原文页在书下面。

### `internal/`：中间产物（只给管理员）

`normalized-document.json`、`normalization-report.json`、`render-config.json`、
`translation-manifest.json`、`translation-checkpoint.json`、`translation-requests.jsonl`
（翻译请求日志，含完整提示词和模型返回）、`translation-diagnostics.json`、
`translation-debug-index.json`、`pipeline-summary.json`、`events.jsonl`、`typst/source.typ`、
`typst/render.pdf`、`ocr-provider/result.json`、`ocr-provider/raw.zip`。下载时文件名把 `/` 换成 `-`。

### 文件清单

`GET /jobs/{job_id}/files` 返回：

```json
{
  "job_id": "…",
  "attempt": 1,
  "source": {
    "name": "source.pdf",
    "url": "http://…/api/v1/documents/<document_id>/files/source.pdf",
    "content_type": "application/pdf",
    "ready": true,
    "on_demand": false,
    "size_bytes": 329,
    "updated_at": "2026-10-17T08:00:00Z",
    "stage": "upload"
  },
  "output": [
    {
      "name": "translated.pdf",
      "url": "http://…/api/v1/jobs/…/files/output/translated.pdf",
      "content_type": "application/pdf",
      "ready": true,
      "on_demand": false,
      "size_bytes": 329,
      "updated_at": "2026-10-17T08:05:00Z",
      "stage": "rendering"
    }
  ],
  "pages": { "url_template": "http://…/api/v1/jobs/…/files/pages/{page}.jpg", "page_count": 12 },
  "internal": [ "…只有管理员和单机模式才有这个字段…" ]
}
```

- `ready`：现在能不能取到；按需生成的文件表示生成它需要的东西都在。
- `size_bytes`：已经在磁盘上的文件才有。
- `updated_at`、`stage`：产物登记表里的更新时间和产出阶段；按需生成、还没生成的为 `null`（2026-10-17 加）。
- `attempt`：这是第几次跑，重跑、重试阶段以后加一（2026-10-17 加）。
- `source`：原文 PDF（2026-10-17 加）。它是书的文件，有书编号时指向 `/documents/{document_id}/files/source.pdf`；
  查不到书编号的任务没有地址：`url` 是空串、`ready` 是 `false`。
- 和已删除的产物清单（`/artifacts-manifest`）比，有意不列这几样：
  - `layout_json`：和 `internal/ocr-provider/result.json` 是同一个文件；
  - 目录（`job_root`、`translations_dir`、`provider_raw_dir`、Markdown 图片目录）：下载不了，请求会回 `409`。

## 书的文件

```http
GET /api/v1/documents/{document_id}/files
GET /api/v1/documents/{document_id}/files/{name}
GET /api/v1/documents/{document_id}/files/pages/{page}.jpg
```

| 文件名 | 内容 | 按需生成 |
|---|---|---|
| `source.pdf` | 原文 PDF | |
| `cover.jpg` | 封面（首页，宽 900） | 是 |
| `thumbnail.jpg` | 缩略图（首页，宽 360） | 是 |
| `pages/3.jpg` | 原文第 3 页，参数同任务的预览图 | 是 |

封面、缩略图带 `Cache-Control: private, max-age=86400`。清单返回 `files`（同上的字段，没有
`size_bytes`）和 `pages`。
