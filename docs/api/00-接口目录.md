共 14 个接口，其中 7 个现用地址、7 个旧地址（还能用，新代码不要再调）。地址前缀省略了 `/api/v1`。

「谁能用」只在多用户模式下起作用：`signed` 登录就能用（路径里的编号要是自己的）、`admin` 只给管理员、
`closed` 对网站账号关闭、`public` 不需要登录。单机版里所有接口都能用。

## 任务 · 操作

| 方法 | 地址 | 谁能用 | 说明 | 旧地址 |
|---|---|---|---|---|
| GET | `/jobs/:job_id/actions` | signed | 现在能做哪些操作（每个阶段能不能重试、重试的请求怎么写） | `/jobs/:job_id/stage-actions` |
| GET | `/jobs/:job_id/actions/resume` | signed | 续跑会从哪里开始 | `/jobs/:job_id/resume-plan` |
| POST | `/jobs/:job_id/actions/resume` | signed | 从断点续跑 | `/jobs/:job_id/resume` |
| POST | `/jobs/:job_id/actions/cancel` | signed | 取消任务 | `/jobs/:job_id/cancel` |
| POST | `/jobs/:job_id/actions/rerun` | signed | 整个任务重跑 | `/jobs/:job_id/rerun` |
| POST | `/jobs/:job_id/actions/retry-stage` | signed | 重试某一个阶段（OCR、翻译、渲染、精修） | `/jobs/:job_id/retry-stage` |
| POST | `/jobs/:job_id/actions/resolve-ocr-ambiguity` | signed | OCR 拿不准时由用户选 | `/jobs/:job_id/ocr/resolve-ambiguity` |
