# 产物与下载

> 文件接口已统一到 `/jobs/{job_id}/files/…` 和 `/documents/{document_id}/files/…`；旧的 `/artifacts`、`/artifacts-manifest`、`/pdf` 等地址已于 2026-10-18 删除（返回 404），本文已改成新地址。新旧对照见 [下载总览](../../api/07-产物下载/01-下载总览.md)，全部接口见 [接口目录](../../api/00-接口目录.md)。

这篇讲任务产物怎么发现、怎么下。

## 文件清单

主接口：

- `GET /api/v1/jobs/{job_id}/files`

它是正式的机器发现入口（取代已删除的 `/artifacts-manifest`，返回结构不同）。按 `output`、`pages`、`internal` 三组列文件。

每项常见字段：

- `name`
- `url`
- `content_type`
- `ready`
- `on_demand`
- `size_bytes`
- `updated_at`
- `stage`

另有 `source`（原文 PDF，书的文件）和 `pages.url_template`。字段细节见 [下载总览](../../api/07-产物下载/01-下载总览.md)。

推荐流程：

1. 先查 `/files`
2. 找目标文件的 `name`
3. 确认 `ready=true`
4. 再用 `url`

## 下载入口

常见下载接口（`output/` 组是成品，`internal/` 组是中间产物，多用户下只给管理员）：

- `/files/output/translated.pdf`
- `/files/output/ocr.md`
- `/files/output/ocr.zip`
- `/files/output/all.zip`
- `/files/internal/normalized-document.json`
- `/files/internal/normalization-report.json`
- `/files/pages/{page}.jpg`（译文页预览图；原文页在 `/documents/{document_id}/files/pages/{page}.jpg`）

Markdown 相关注意：

- `reader/markdown` 返回 JSON 包装
- `files/output/ocr.md` 返回原始 Markdown
- `ocr.zip`（Markdown + 图片）是最适合前端直接下载的包

页级预览图用于阅读器首屏兜底：

- 返回 `image/jpeg`
- 使用强缓存：`Cache-Control: public, max-age=31536000, immutable`
- 返回稳定 `ETag`
- 按 job 缓存在 `artifacts/` 下

## 四层边界

后端对外看四层：

- `provider raw`
- `normalized`
- `published artifact`
- `download API`

不要把目录结构当公开契约。

## 排错入口

如果按钮不可点，先看：

- `actions.*.enabled`
- `artifacts.*.ready`
- `GET /jobs/{job_id}/files` 里每一项的 `ready`

如果下载失败，优先看：

- `failure`
- `runtime`
- `log_tail`
- `progress/events`
